# Weekly Dashboard Views — Plausible

Set up these saved views in Plausible to monitor weekly.

## 1. Newsletter Signups by Source (last 7 days)
- **Filter**: Goal = "Subscribe Click"
- **Breakdown by**: Property "location"
- **Time range**: Last 7 days
- **What to look for**: Which form locations drive the most signups. Hero and modal typically dominate; blog-inline shows content-driven conversion.

## 2. ROI Calculator to Newsletter Conversion Rate
- **View 1**: Goal = "ROI Calc Started" (last 7 days) — note count
- **View 2**: Goal = "ROI Calc Email Submitted" (last 7 days) — note count
- **Calculate**: Email Submitted / Started = conversion rate
- **Target**: 20-35% is healthy for a gated calculator
- **Breakdown by**: Property "market" on the Submitted goal to see which markets drive the most signups

## 3. Advisory CTA Click to Form Submit
- **View 1**: Goal = "Advisory CTA Click" — note count and breakdown by "location"
- **View 2**: Goal = "Advisory Form Submitted" — note count
- **Calculate**: Submitted / Clicked = advisory funnel conversion
- **Breakdown**: Property "tier" on Submitted to see which tier gets the most interest

## 4. Top 10 Blog Posts by Signups Generated
- **Filter**: Goal = "Subscribe Click", Property "location" = "blog-inline"
- **Breakdown by**: Page
- **Sort**: By conversions, descending
- **What to look for**: Which blog posts drive the most inline subscribe conversions — double down on those topics

## 5. Mobile vs Desktop Signup Rate
- **Filter**: Goal = "Subscribe Click"
- **Breakdown by**: Device type
- **Compare**: Mobile conversion rate vs Desktop conversion rate
- **What to look for**: If mobile converts significantly lower, investigate form usability on small screens
