# Cloud Site Audit — 2026-10-17

## Status (HEALTHY / ISSUES / P0 ALERT)
**P0 ALERT → fixed today.** 14 signup forms were silently sending nothing because the site's own CSP blocked them. The fix is in today's content push. Publishing and research are both alive.

## Alerts
- **P0 (fixed): signup forms did nothing.**
  - 11 blog pages used `onsubmit="handleInlineSub(...)"` and 2 used `onsubmit="handleSubscribe(...)"`. The CSP rule `script-src-attr 'none'` blocks those handlers, so the browser did a GET reload and no request was sent.
  - `/guides.html` posted to `formspree.io`, which `form-action 'self'` blocks.
  - Both were confirmed in a real browser: no request was sent, and the console showed a CSP error.
- Publishing is alive: Add guide / quick-read / tip commits on 2026-10-16. Research is alive: `Research:` commits on 10-16 and 10-17.
- An owner alert was sent by push notification.
